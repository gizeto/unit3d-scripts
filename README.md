# UNIT3D Scripts

- [Install IMDb Technical Specs](https://raw.githubusercontent.com/gizeto/unit3d-scripts/master/imdb-tech-specs.user.js) — adds runtime and technical-specification details.
- [Install IMDb Parental Guidance](https://raw.githubusercontent.com/gizeto/unit3d-scripts/master/imdb-parental-guidance.user.js) — adds parental-guide categories, severity ratings, and notes.
- [Install Favorite Subtitle Flags](https://raw.githubusercontent.com/gizeto/unit3d-scripts/master/subtitle-flags.user.js) — shows flags for configured subtitle languages in torrent lists.

Open an installation link with Tampermonkey or Violentmonkey enabled to install the script and receive future updates. The IMDb panel positions can be changed from their userscript menus. Favorite Subtitle Flags requires a per-site API key, also configured from its userscript menu.
